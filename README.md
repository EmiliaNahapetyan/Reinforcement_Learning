# **🧠 Reinforcement Learning Projects**

Welcome to my **Reinforcement Learning (RL)** project repository! This collection showcases a variety of RL implementations, each aimed at strengthening my understanding of:

- 🧑‍💻 **Agent training** and policy optimization  
- 🎯 **Reward design** and environment feedback  
- 🤖 **Decision-making** in dynamic and stochastic environments  

These projects are hands-on experiments with RL fundamentals, structured implementations, and exploratory techniques for training intelligent agents.

---

## **📌 Project Highlights**

Each project is placed in its own directory, complete with:  
✅ A clear **goal and motivation**  
✅ Description of **algorithms used**  
✅ Summary of **results and insights**

## **🚀 Getting Started**

To try out any project:

### 1️⃣ Clone the repository  
```bash
git clone https://github.com/EmiliaNahapetyan/Reinforcement-Learning.git
cd Reinforcement-Learning
```

### 2️⃣ Enter the project folder  
```bash
cd project-1
```

### 3️⃣ Install dependencies  
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the main script  
```bash
python main.py  # or train.py depending on the setup
```

## **📁 Projects Included**

### ✅ **1. Foundational Algorithms**
- Classic RL methods: **Q-Learning**, **SARSA**, **Monte Carlo**
- Implemented in small-scale, intuitive environments

### ✅ **2. Policy Optimization**
- Exploration of **DQN**, **Policy Gradients**, and **Actor-Critic**
- Focus on training efficiency and reward shaping

### ✅ **3. Custom Environments**
- Designing environments from scratch or extending **OpenAI Gym**
- Tailored to test agent behaviors in unique settings

### ✅ **4. Evaluation & Tuning**
- Systematic experimentation with learning rates, rewards, and architectures  
- Comparative analysis of performance metrics
