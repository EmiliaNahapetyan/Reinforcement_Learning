# Mountain Car – Eligibility Traces (ET) Implementation

This repository contains a clean and modular implementation of the **Mountain Car** reinforcement-learning environment, including **tile coding**, **semi-gradient TD methods**, and **eligibility traces**, along with utilities for generating and comparing figures with those from the Sutton & Barto *Reinforcement Learning* textbook.

## Project Structure

```
mountain-car-et/
│
├── book_images/              # Reference figures from the RL textbook
│   ├── Figure_12_10.PNG
│   └── Figure_12_11.PNG
│
├── generated_images/         # Figures generated by the code in this project
│   ├── figure_12_10.png
│   └── figure_12_11.png
│
├── notebooks/
│   └── mountain_car.ipynb    # Interactive experiments and visualization
│
└── src/
    ├── __init__.py
    ├── mountain_car.py       # Environment definition and dynamics
    └── tile_coding.py        # Tile coder and feature-representation utilities
```


## Getting Started

### Requirements
Recommended minimal environment:

- Python 3.8+
- NumPy
- Matplotlib
- Jupyter Notebook (for working with the notebook)


## Usage

### 1. Running the Notebook
To run training experiments and generate plots:

```
jupyter notebook notebooks/mountain_car.ipynb
```

The notebook demonstrates:
- Tile coding visualization
- Learning curves with different λ values
- Replication of textbook figures

### 2. Using the Source Code in Scripts

```python
from src.mountain_car import MountainCar
from src.tile_coding import TileCoder

env = MountainCar()
tc = TileCoder(num_tilings=8, tiles_per_dim=[8, 8])

features = tc.get_features(env.state)
```
