# 🎲 Random Walk (n-step TD)

This repository implements the **Random Walk** example from *Sutton & Barto’s Reinforcement Learning: An Introduction* — focusing on **n-step Temporal-Difference (TD)** methods.  
It visualizes how learning progresses with different step sizes and compares TD with Monte Carlo approaches.

## 📘 Description

This project covers:
- Implementation of **n-step Temporal-Difference learning**.
- Comparison with **Monte Carlo** and **TD(0)** methods.
- Visualization of prediction errors during learning.
- Reproduction of textbook figures, including *Figure 7.2*.

The `notebooks/random_walk.ipynb` notebook allows for interactive visualization and experimentation, while `src/random_walk.py` provides the implementation logic.
