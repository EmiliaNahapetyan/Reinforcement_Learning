# 🌀 Random Walk with Function Approximation

This repository contains experiments and implementations from **Reinforcement Learning (Sutton & Barto, 2nd Edition)**, focusing on **random walk prediction problems** using **function approximation** techniques.

The project reproduces and extends several figures and experiments from the book using modern Python tools and Jupyter notebooks.

## 🧠 Overview

This project demonstrates **value prediction in a random walk environment** using different **function approximation** methods, including:

- **State aggregation**
- **Tile coding**
- **Polynomial basis**
- **Fourier basis**

Each notebook explores a different representation, visualizes learning dynamics, and reproduces book figures for comparison.

---

## 🧩 Implemented Concepts

| Concept | Description |
|----------|-------------|
| 🔁 Bootstrapping | Combines sampling and learning from previous estimates |
| 🧱 State Aggregation | Groups states to simplify learning |
| ⚙️ Tile Coding | Feature-based encoding of continuous spaces |
| 🔣 Polynomial & Fourier Bases | Function approximations for value prediction |
| 📊 Random Walk | Environment setup and return estimation task |
