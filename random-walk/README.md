# 🚶‍♂️ Random Walk Project

A project for generating, analyzing, and visualizing random walk simulations. This repository includes source code, Jupyter notebooks, and image outputs to explore concepts related to random walks, potentially for educational or illustrative purposes (e.g., for a book or tutorial).

---

## 📁 Project Structure

```
random-walk/
├── .idea/               # Project settings (for JetBrains IDEs)
├── book_images/         # Images intended for publication or documentation
├── generated_images/    # Images generated during random walk simulations
├── notebooks/           # Jupyter notebooks for experiments and visualization
├── src/                 # Source code for random walk logic and utilities
```

---

## 🚀 Installation

```bash
git clone https://github.com/EmiliaNahapetyan/random-walk.git
cd random-walk
# (optional) create a virtual environment
pip install -r requirements.txt
```

---

## 📓 Usage

You can start by exploring the Jupyter notebooks:

```bash
cd notebooks
jupyter notebook
```

Or run simulations directly via scripts in the `src/` folder.

---

## 📦 Dependencies

- Python 3.8+
- NumPy
- Matplotlib
- Jupyter
