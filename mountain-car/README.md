## 🚀 Description

The **Mountain Car** problem is a continuous-state reinforcement learning environment where an underpowered car must drive up a steep hill.  
The challenge lies in learning to leverage momentum — driving *back and forth* — to reach the goal efficiently.

This project reproduces **Figures 10.1 – 10.4** from the textbook, comparing **book reference figures** (`book_images/`) with **generated results** (`generated_images/`).

---

## 🧠 Core Concepts

- **Tile Coding:**  
  Converts continuous state variables (position, velocity) into high-dimensional binary features.
- **Function Approximation:**  
  Uses linear value estimation for large/continuous state spaces.
- **Semi-gradient Methods:**  
  Implements TD-learning with approximations.
- **Policy Control:**  
  Employs ε-greedy exploration over Q-value estimates.
