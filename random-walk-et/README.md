# Random Walk Simulation

Reproducing Figures from *Python Crash Course* (2nd Edition), Chapter 12

This repository contains a simple implementation of a **2D random
walk**, together with code and notebooks that reproduce several figures
from Chapter 12 of *Python Crash Course (2nd Edition)*.\
The project generates visualizations of long random walks and compares
them with the corresponding figures from the book.

## Features

### • Random Walk Implementation

The core logic is implemented in `src/random_walk.py`.\
It creates random paths by moving one step at a time in a random
direction.
