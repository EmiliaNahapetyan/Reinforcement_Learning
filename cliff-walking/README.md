# 🧗‍♂️ Cliff Walking Project

This repository is dedicated to the **Cliff Walking** problem — a classic example in reinforcement learning, often used to test gridworld-based policy learning algorithms.

---

## 📁 Project Structure

```
cliff-walking/
├── .idea/                # IDE-specific settings
├── book_images/          # Diagrams and illustrations for documentation or books
├── generated_images/     # Dynamically created images (e.g., training visualizations)
├── notebooks/            # Jupyter Notebooks for experiments and visual analysis
├── src/                  # Source code: environment setup, agent logic, algorithms
```

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EmiliaNahapetyan/Reinforcement_Learning.git
   cd Reinforcement_Learning/cliff-walking
   ```

---

## 📓 Notebooks

Explore experiments, visualizations, and model training inside the `notebooks/` folder. These are ideal for understanding and debugging the learning process.
