# 📊 Updates Comparison

A project for comparing generated results with reference materials (e.g., textbook figures).  
This repository includes scripts, Jupyter notebooks, and visual assets used for experiments and analysis.

---

## 📁 Project Structure

```
updates-comparison/
├── book_images/          # Reference images from textbooks or papers
│   └── Figure_8_7.PNG
├── generated_images/     # Images generated during experiments
│   └── figure_8_7.png
├── notebooks/            # Jupyter notebooks for analysis and visualization
│   └── expectation_vs_sample.ipynb
├── src/                  # Source code for experiments and utilities
│   ├── __init__.py
│   └── expectation_vs_sample.py
```

---


## 📓 Notebooks

- `expectation_vs_sample.ipynb` – Interactive exploration of theoretical expectations vs. sampled results.
