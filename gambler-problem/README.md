## 🎯 Description

This project explores the **Gambler’s Problem**, where a gambler makes bets on the outcome of a coin flip, aiming to reach a target amount.  
It includes:

- A **Dynamic Programming** solution via **Value Iteration**.
- Visualization of the final policy and value function.
- Replication of results similar to those in the textbook.
