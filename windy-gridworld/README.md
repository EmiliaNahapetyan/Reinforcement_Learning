# 🌬️ Windy Gridworld

A reinforcement learning project based on the classic "Windy Gridworld" environment, as introduced in Sutton & Barto's *Reinforcement Learning: An Introduction*. This project includes implementations, visualizations, and experiments using various RL algorithms.

---

## 📁 Project Structure

```
windy-gridworld/
├── .idea/               # Project settings (for JetBrains IDEs)
├── book_images/         # Images for documentation or publication
├── generated_images/    # Output images from simulations and visualizations
├── notebooks/           # Jupyter notebooks for experimenting with RL agents
├── src/                 # Source code: environment and agent implementations
```

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EmiliaNahapetyan/Reinforcement_Learning.git
   cd Reinforcement_Learning/windy_gridworld
   ```

2. **Set up a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
